# Security Policy

SL Option is intended to become a financial application. Security bugs affecting authentication, authorization, wallet behavior, order handling, sensitive data exposure, or dependency integrity should be treated as high priority.

Please do not publish exploitable details in a public issue. Report security concerns privately to the project maintainers with enough detail to reproduce the issue safely.

## Scope

This repository is the web client. The web client must never be treated as an authority for balances, order execution, settlement, KYC decisions, or financial authorization.
