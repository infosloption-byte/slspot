# Midnight Signal design system

## Concept

A calm, instrument-grade terminal rather than a casino-like interface: dark graphite, quiet borders, sparse accent colors, dense information blocks and clear action hierarchy.

## Tokens

- Background: `--bg-0`, `--bg-1`, `--bg-2`
- Surfaces: `--panel`, `--panel-strong`, `--panel-soft`
- Accent: `--cyan`
- Attention: `--amber`
- Positive: `--green`
- Negative: `--red`
- Text: `--text`, `--muted`, `--muted-2`

## Layout principles

- Chart gets the largest continuous canvas.
- Asset discovery is persistent but visually quiet.
- Order entry stays in one predictable right-hand zone on wide screens.
- Secondary data lives below the chart rather than creating long vertical scrolls.
- Mobile collapses into stacked workspaces without hiding core actions.
- Controls use short labels and familiar iconography.
